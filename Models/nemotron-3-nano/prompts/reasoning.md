# Reasoning & Analytical Thinking Tests

These prompts evaluate multi-step reasoning, logic,
and structured problem-solving.

---

## Prompt 1: System Design Reasoning

### Prompt
You are designing an AI-powered customer support assistant
for a SaaS company with 1 million users.

Explain how you would:
- Handle ambiguous user queries
- Reduce hallucinations
- Decide when to escalate to a human
- Measure response quality

Think step by step before giving the final answer.

### Model
NVIDIA Nemotron 3 Nano 30B-A3B

### Settings
- Temperature: 0.2
- Max Tokens: 1024

### Expected Behavior
- Clear reasoning steps
- Trade-off analysis
- Practical decision-making
