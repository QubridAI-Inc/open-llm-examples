# Long Context & RAG Prompt Tests

These prompts evaluate a model’s ability to handle large inputs,
retain context, and reason across long documents.

---

## Prompt 1: Large Document RAG Design

### Prompt
You are given a 50-page technical document.

Design a scalable Retrieval-Augmented Generation (RAG) system that:
- Handles long documents efficiently
- Supports citations
- Maintains conversational memory
- Controls inference cost

Explain your approach step by step.

### Model
NVIDIA Nemotron 3 Nano 30B-A3B

### Settings
- Temperature: 0.2
- Max Tokens: 2048

### Expected Behavior
- Structured system design
- Clear reasoning
- Long-context awareness
- Practical, production-ready guidance
